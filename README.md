# Deep-Residual-Learning-for-Image-Recognition
• Implemented ResNet residual blocks with identity shortcut connections to learn residual mappings and address
optimization challenges in increasingly deep CNN architectures for image classification and feature learning tasks
• Analyzed the degradation problem by comparing plain convolutional networks with residual networks and
studying the effect of network depth on training convergence, optimization difficulty, and classification accuracy
• Explored residual learning and deep feature extraction for image classification, focusing on how shortcut connec-
tions enable effective and efficient training of substantially deeper and more complex neural network architectures
